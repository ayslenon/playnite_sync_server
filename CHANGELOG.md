# Changelog — Backend

## 1.3.0 — 2026-08-16

- Incorporados os mapeamentos Playnite para macOS, Nintendo Game Boy Advance/SNES e Sony PlayStation, PlayStation 2/PSP.
- Aceitos status de conclusão em português (`Jogando`, `Finalizado` e `Abandonado`).
- Gêneros vazios do Playnite permanecem como lista vazia, sem inserir `Outro` artificialmente.
- Capas e backgrounds agora são normalizados e persistidos como URLs relativas, inclusive para payloads antigos.
- Mantidos HTTPS local, hostname mDNS, scripts Linux/Windows, operação dual boot e PWA servido pelo backend.
- Documentação atualizada para o banco NTFS compartilhado e o contrato relativo de assets.

## 1.2.1

- Correção do diretório de capas e atualização inicial dos mapeamentos Playnite.
